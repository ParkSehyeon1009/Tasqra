#   (torch 527MB + cuDNN 366MB + nvidia_* 다수). paddleocr 가 이미 들어있는
#   이미지에 CUDA 스택이 얹힌 결과다.
#
#   **이것은 실수가 아니라 판단이다** (2026-08-21). GPU 를 쓸 수 있는 환경을
#   전제하고 리랭킹까지 살리기로 했다. 크기를 줄이려다 리랭킹을 잃는 것보다

#
#     1) CPU 전용 휠 — 이미지 약 4GB
#        pip install torch --index-url https://download.pytorch.org/whl/cpu
#        ⚠️ 리랭킹이 후보 10건에 8.5초가 되어 못 쓴다(GPU 527ms).
#           RERANK_ENABLED=false 로 두고 검색 limit 을 10 으로 올려라 —
#           문서 단위 k=10 이 97.2% 로 리랭커를 켠 k=5(96.3%)보다 오히려 높다.
#
#     2) EMBEDDING_PROVIDER=local-http — 이미지가 원래대로 돌아간다

#        없으므로 GPU 도 서버 쪽에서만 쓰면 된다. 대신 서버를 띄워 둬야 한다.
